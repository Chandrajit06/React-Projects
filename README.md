# React Features

A collection of small React projects built to practice core React concepts — hooks, Context API, routing, and component composition. Each feature lives in its own folder under `src/components` and is wired together with `react-router-dom` for easy navigation between demos.

## 🚀 Features

| Project | Description |
|---|---|
| **BgChanger** | Changes the page background color on click, demonstrating basic state management. |
| **Counter** | A simple increment/decrement counter to practice `useState`. |
| **CurrencyConverter** | Converts amounts between currencies using live/mock exchange rates. |
| **PasswordGenerator** | Generates random passwords with customizable length and character sets, using `useState`, `useCallback`, `useEffect`, and `useRef`. |
| **ThemeSwitcher** | Toggles light/dark mode using the Context API, a custom hook, and Tailwind's dark mode utilities. |
| **TodoApp** | A basic to-do list app for practicing CRUD-style state updates. |

## 🛠️ Tech Stack

- **React** (functional components + hooks)
- **React Router** for navigation between features
- **Context API** for global state (theme)
- **Custom Hooks** for reusable logic
- **Tailwind CSS** for styling
- **Vite** as the build tool

## ⚙️ Getting Started

1. Clone the repository
   ```bash
   git clone <repo-url>
   cd Features
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Run the development server
   ```bash
   npm run dev
   ```
4. Open the app in your browser at the local URL shown in the terminal (typically `http://localhost:5173`).

## 🎯 Purpose

This repo serves as a hands-on playground for strengthening React fundamentals ahead of technical interviews — focusing on hooks, state management patterns, and clean component architecture.
